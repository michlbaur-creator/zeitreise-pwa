# Zeitreise – Die Geschichte des Lebens

Dieses Projekt wird als Progressive Web App für `evo.mibaso.de` aufgebaut.

## Ordner

- `Dokumente/01_Quellen`: ursprüngliche Arbeitsdokumente
- `Dokumente/02_Verbindlich`: konsolidierte und freigegebene Fassungen
- `Bilder`, `Audio`, `Animationen`: Medien für die Episoden
- `App`: die späteren Programmdateien der PWA

Für Episode 1 ist `Dokumente/02_Verbindlich/Zeitreise_Episode1_Musterepisode_V1.0.docx` verbindlich.
